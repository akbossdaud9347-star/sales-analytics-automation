# Sales Analytics Automation

A Python-based automation project that processes sales data and generates an Excel report with business analysis and dashboard charts.

## Overview

This project takes sales data from an Excel file and automatically performs sales calculations and analysis.

The generated report includes monthly sales, product performance, category performance, salesperson performance, and a summary dashboard.

## Features

- Excel sales data processing
- Automatic sales calculation
- Monthly sales analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Salesperson performance analysis
- Total sales calculation
- Total orders calculation
- Average order value calculation
- Excel dashboard
- Automated charts

## Technologies

- Python
- Pandas
- OpenPyXL
- Microsoft Excel
